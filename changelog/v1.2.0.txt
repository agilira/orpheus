Orpheus v1.2.0 - Feature Release
==================================

Release Date: April 11, 2026
Type: Feature Release

NEW FEATURES
-------------

Interactive Prompts (Prompter Interface):
  New Prompter subsystem for interactive CLI wizards and user input.
  Designed with the same interface-first doctrine as the rest of Orpheus.

  - Ask(prompt, defaultVal) -- free-text input
  - AskSecret(prompt) -- masked password/token input (via x/term)
  - Choose(prompt, options) -- single-select menu
  - Confirm(prompt, defaultVal) -- yes/no confirmation

  Fully testable: inject a mock Prompter via App.SetPrompter() for
  deterministic test execution without terminal interaction.

BUG FIXES
----------

splitGlobalArgs Edge Cases:
  Fixed parsing of negative numbers and dash-prefixed values passed to
  global flags.  --offset -5 and --pattern --something now work correctly.

  - New isValueGlobalFlag() helper identifies non-boolean global flags
  - For long flags, merges --flag -value into --flag=-value form as
    defense-in-depth (flash-flags v1.1.7 also fixes this at the parser level)
  - Added POSIX -- (double-dash) end-of-flags sentinel support
  - 27 new tests in splitargs_test.go covering negative numbers,
    dash values, embedded equals, double-dash sentinel, bool flag
    interaction, mixed flags, and edge cases
