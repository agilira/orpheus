Orpheus v1.9.0 - GetArg Reads the Arguments
===========================================

Release Date: 2026-11-24
Type: Minor (behaviour change)

CHANGED
-------
- Context.GetArg and Context.ArgCount return the positional arguments:
  flags and their values are excluded, wherever they are written.

      app remote add -f origin URL     GetArg(0) == "origin"

  They indexed ctx.Args, the raw arguments, so a flag written before the
  operands was read as one. The README and the examples call GetArg(0) for
  the first operand, and examples/gitlike added a remote named "-f". A
  required-argument check such as "ArgCount() < 2" counted the flag too.

  ctx.Args keeps the raw arguments, flags included. A Context built outside
  the dispatch path, with no parsed flags, reads ctx.Args as before.
  Positional, PositionalCount and GetPositional (v1.3.0) return the same
  arguments as GetArg and ArgCount now.

FIXED
-----
- A not-found error names the command once. Error() read

      command 'stauts': [ORF1002]: command 'stauts' not found

  and now reads "command 'stauts': [ORF1002]: unknown command". An unknown
  subcommand is reported on its parent:
  "command 'remote': [ORF1002]: unknown subcommand 'ad'".

- The nested example modules did not build: their go.mod files still
  required go-errors v1.1.2 while the library requires v1.1.3, and Go
  stopped with "updates to go.mod needed". All are tidied.

- examples/gitlike prints its errors as "gitlike <command>: <message>",
  followed by the usage, example and suggestion its handlers attach,
  instead of a log line with a timestamp and the generic "Command or
  resource not found". remote list aligns the names.

CHANGED (documentation)
-----------------------
- README: a new demo recorded from examples/gitlike, a GIF in the
  repository (assets/demo.gif, regenerated by assets/demo.sh), since the
  asciinema image no longer loaded on GitHub. The Go Report Card badge is
  removed, the service no longer exists.
- docs/API.md and docs/EXAMPLES.md describe GetArg as positional.

TESTS
-----
- getarg_test.go: GetArg and ArgCount with flags before, between and after
  the operands, without parsed flags, and the not-found messages.
